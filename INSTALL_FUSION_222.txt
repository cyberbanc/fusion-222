FUSION-222 REAL v1.0.0
======================

The real service mirrors the exact locked paper decision for each epoch from
REFERENCE_DECISIONS_TABLE. It never calculates a second independent signal.

1. Keep the existing Railway service `fusion-222` on GitHub branch `main`.
2. Create a second Railway service `fusion-222-real` from branch `live-real`.
3. Connect the same Railway Postgres with DATABASE_URL=${{Postgres.DATABASE_URL}}.
4. Add the variables from RAILWAY_VARIABLES_FUSION_222.txt with WORKER_ENABLED=false.
5. Add WALLET_PRIVATE_KEY directly in Railway. Never place it in GitHub, Tilda,
   logs, support messages or chat. Optionally set WALLET_ADDRESS as an exact
   address-match safety check.
6. Deploy and verify:
   - /health: database_connected=true
   - execution.ready=true
   - displayed wallet address and balance match MetaMask
   - tables all start with fusion222_real_ except the two read-only sources
7. Set WORKER_ENABLED=true only after those checks pass.
8. Open /dashboard. The same HTML is in TILDA_FUSION_222_REAL.html for a separate
   Tilda T123 block.

Rollback: set WORKER_ENABLED=false. This stops new decisions/transactions and
does not affect the paper service or either history.
